## Ключевые решения (не пересматривать без причины)

- **Override поверх seed**: правка базовой карточки сохраняется моделью под тем
  же id и перекрывает seed при merge; «Сбросить» = удалить модель. Без копий.
- **Редактор админки открывает СЫРУЮ модель** (`rawModels`), не развёрнутую —
  иначе запекание `size_anchors` глушит `grade_rule`.
- **Минимальный тех-лист** — только 3 значения (размер изделия, отступ мм,
  размер макета мм) + шкала 100 мм; подписи latin-safe (кириллицы нет в
  стандартных шрифтах jsPDF).
- **Регрейдинг**: отступ от шва горловины — константа между размерами
  (BUILD.md §4); рукав — от нижнего края.
- **Якоря и зоны — в мм** (не в единицах SVG); комментарий-ловушка в types
  исправлен в PR #48. Ширина флэта в мм = naturalWidth × scale_mm_per_unit.
- **Категории «Одежда/Аксессуары» НЕ хранятся** — выводятся из `GarmentType`
  через `GARMENT_TYPE_CATEGORY` (types/index.ts; shopper → accessory). У
  аксессуаров нет горловины: схема не требует `neckline_point` (ось обязательна),
  геометрия по отсутствию горловины даёт panel-якорь (отсчёт от верха зоны, от
  оси), `stripAccessoryNeckline` срезает легаси-горловины при merge и при
  сохранении в админке (rawModels не трогаем). UI-гейты — по категории.
- pdfjs worker — статикой из `public/` через postinstall (webpack его не парсит).
- Экспорт из UI: «минимальный» вариант заменил полный (решение менеджера);
  production-вариант остаётся для цеха.
- **Фото-мокапы удалены** (решение юзера): клиентское PNG-превью всегда
  строится из флэта карточки (перекраска в цвет изделия), подсистема
  фото+маска+зона-на-фото вырезана целиком.
- **Аксессуары — ONE SIZE**: `BaseSize = M | L | "ONE SIZE"`, шопперы в seed
  безразмерные. Значение латиницей — минимальный тех-лист печатает метку
  размера, а шрифты jsPDF без кириллицы; кегль метки адаптивный (34/20).
  Старые сохранённые проекты шопперов со `size:"M"` мягко падают на базовую
  геометрию (везде фоллбэк на базу) — не чиним, таких проектов скорее всего нет.
- **Допустимые методы печати у зоны** — `PrintArea.methods?: PrintMethod[]`
  (пусто/нет = все допустимы; инвариант default_method ∈ methods).
  Конфликт метод↔зона — warn (preflight/инспектор), не жёсткий блок;
  «На все зоны» пропускает несовместимые, «Копировать на вид» берёт первую
  совместимую. Seed-зоны без ограничений — задаёт админ чекбоксами.

## Известное / отложенное (не баги прода)

- **Данные от менеджера не получены**: реальные размеры печатных зон и позиции
  выточек для всех SKU кроме FreeFit — зоны предварительные. Ждём — это
  data-entry через админку, кода не требует.
- Размеры всех SKU кроме FreeFit — только M; ростовки добавлять через админку
  (grade_rule или per-size якоря).
- Латентно (низкий приоритет, зафиксировано ревью #48):
  - preflight min/max сравнивает сырые w/h нанесения, а `out_of_zone` — по
    повёрнутому AABB (рассогласование метрик при повороте);
  - растровый флэт + выбор цвета изделия: recolor вернёт мусор → флэт исчезнет
    (в текущем каталоге растровых флэтов нет);
  - SVG-макет без width/height трактует viewBox как мм и НЕ помечает размер
    оценочным (`size_estimated=false`);
  - «Дублировать» в списке админки пресохраняет копию до открытия редактора
    (выход без сохранения оставляет орфан);
  - стрелки/тогглы флудят undo-историю (лимит 50 вытесняется быстро).
- `*-copy-*` карточки старого формата — обычные кастомные, специальной
  обработки нет и не нужно.

## Рабочие процессы (проверено на практике)

- Деплой = merge PR в main; готовность прода ~40-60 с; маркер новой сборки —
  сравнить что-то изменившееся (например, новый роут) курлом.
- Прод-смоук: `curl` по `/`, `/admin`, `/editor`, `/icon.svg`,
  `/pdf.worker.min.mjs` (все 200); Supabase — round-trip через supabase-js.
- Конвейер новых флэтов: .ai → `scripts/visuals_batch.py` (маппинг страниц в
  `visuals-batch-config.json`) → `public/seed/flats/` → записи в skus.json →
  контрактные тесты recolor (seedFlats.test.ts) сами подхватят новые файлы.
- Миграции Supabase — идемпотентный SQL через MCP `apply_migration`
  (`if not exists` / `drop policy if exists`).
